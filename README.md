# Hideout — Dread Hunger modpack

Автоматическая лента обновлений сборки Hideout для нашей частной группы Dread Hunger.

В репозитории находятся только моды, локализация, исправления и манифесты обновлений. Файлы самой игры не публикуются.

- `stable.json` — стабильная сборка для команды.
- `test.json` — тестовая сборка владельца сервера.
- `Hideout Launcher` проверяет файлы по SHA-256 перед установкой.
- При ошибке обновления лаунчер возвращает предыдущие файлы.
- Обычный `DreadHunger.exe` запускает чистую игру; `Hideout Launcher.exe` — изолированную сборку с модами.

Текущая открытая бета-версия: **Hideout 1.2** (`test.json`).

Локально у игрока хранится только исходная резервная копия, которая нужна для полного
удаления Hideout и возврата к чистой игре. Временные откаты уже установленных обновлений
удаляются после успешной проверки новой версии. В репозитории сохраняются как минимум
две предыдущие опубликованные версии файлов обновления.
