# DH12 Dread Hunger — update feed

Автоматическая лента обновлений модпака для нашей частной группы Dread Hunger.

В репозитории и Releases находятся только моды, локализация, исправления и манифесты обновлений. Файлы самой игры не публикуются.

- `stable.json` — стабильная сборка для команды.
- `test.json` — тестовая сборка владельца сервера.
- Все файлы перед установкой проверяются `DH12 Launcher` по SHA-256.
- При ошибке установки лаунчер возвращает предыдущие файлы.

Текущая стабильная версия: **1.1.5**.
