# Hideout 1.2.1

Дата выпуска: 13 августа 2026 года.

## Исправление использования места

- Из клиентской копии Hideout удаляются неиспользуемые сборки выделенного сервера для Windows и Linux.
- Удаляются старые резервные копии прошлых версий мода и временные файлы обновлений.
- Единственная резервная копия исходных файлов Dread Hunger сохраняется: она нужна для безопасного удаления Hideout и возврата к чистой игре.
- Большие общие файлы клиента по возможности переводятся из жёстких ссылок в символические. Для этого Windows один раз может запросить права администратора.
- Если пользователь отклонит запрос прав, обновление и запуск игры продолжатся, а повторно окно показываться не будет.
- Оптимизация не трогает файлы, пока Dread Hunger запущен.

## Важно

До обновления Проводник Windows мог показывать около 42 ГБ, потому что считал одни и те же данные дважды через жёсткие ссылки. Фактически эти данные уже занимали место на диске только один раз.

Клиентская и серверная совместимость с Hideout 1.2.0 сохранена. Номер `1.2.1` — технический хотфикс ветки Hideout 1.2.
