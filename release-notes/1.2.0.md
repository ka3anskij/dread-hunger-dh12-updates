# Hideout 1.2

Дата выпуска: 12 августа 2026 года.

## Что изменилось

- У лаунчера появился собственный значок с кораблём Hideout.
- Версия в интерфейсе игры обновлена до `Hideout 1.2`.
- Лаунчер удаляет временные откаты после успешно установленного обновления.
- При обновлении удаляются старые локальные резервные копии прошлых версий мода.
- Единственная резервная копия оригинальных файлов Dread Hunger сохраняется для безопасного удаления мода и возврата к чистой игре.
- В серверной панели `Соло-режим` и `Бессмертие` разделены: любой из них можно включить независимо.
- Исправлено сопоставление новых персонажей на экране результатов; для них используются имена и портреты игроков с сохранением красных и синих рамок команд.

## Совместимость

- Клиентская версия: `1.2.0`.
- Серверная версия: `1.2.0`.
- Карты: Подступ, Вершина и Просторы.
- Archipelago пока не входит в релиз.

## Хотфиксы Hideout 1.2

### Очистка клиентской папки — 13 августа 2026 года

- Из клиентской копии Hideout удаляются неиспользуемые сборки выделенного сервера для Windows и Linux.
- Удаляются старые резервные копии прошлых версий мода и временные файлы обновлений.
- Единственная резервная копия исходных файлов Dread Hunger сохраняется: она нужна для безопасного удаления Hideout и возврата к чистой игре.
- Большие общие файлы клиента по возможности переводятся из жёстких ссылок в символические. Для этого Windows один раз может запросить права администратора.
- Если пользователь отклонит запрос прав, обновление и запуск игры продолжатся, а повторно окно показываться не будет.
- Оптимизация не трогает файлы, пока Dread Hunger запущен.

До хотфикса Проводник Windows мог показывать около 42 ГБ, потому что считал одни и те же данные дважды через жёсткие ссылки. Фактически эти данные уже занимали место на диске только один раз.

### Карточки новых персонажей в результатах — 14 августа 2026 года

- Исправлено чтение имени игрока из записи повтора: раньше мод обращался к массиву статистики вместо объекта игрока, поэтому не находил сохранённый портрет.
- Для новых персонажей в результатах используется портрет из стартовой карточки и настоящее имя игрока.
- Название новой роли сохраняется в момент её назначения, до преобразования во внутреннее значение `PTR_UNKNOWN`.
- Красные и синие рамки команд остаются стандартными.
